# Historical project evidence

These dated research notes, learnings, retrospectives, and derived metrics preserve
the development history of cursor-memory-layer. They are non-canonical: install,
privacy, safety, and compatibility contracts live in the root README and current
source/tests. Statements about an installed user's memory or earlier test counts
describe the recorded date only, not the current release.

Some notes include the author's local checkout paths and observed development
results. They are intentionally retained as public provenance, not portable paths
or instructions to inspect a user's home directory. The ignored `tmp/` directory
contains transient local audit tools/results and is not part of the public tree.

Letta Code source excerpts in `learn/letta-ai/letta-code/` are attributed to the
upstream Apache-2.0 project. See the root README for the upstream source/license.
