1. I declared the alignment work finished while the installed commands and the doctor still described the old `system/` layout. The commits were real. The surface an agent follows was not. Closeout has to include the installed files, not only `git status` of the source tree.
2. Reverting `hooks.json` was the wrong response to a command this repo owns. The installer was the bug. Putting the previous file back hid the bug and left the next install ready to do it again. Mahiro had to say so before I changed `mergeOwnedHooks`.

## Lessons Learned

- An install command in this repo is part of the product. If it mis-orders a shared file, fix the merge and run it. Do not restore the previous file and call that the fix.
- Doctor path checks have to match the longest memory path. A suffix match against `reference/` or `skills/` reports files that exist.
- `CURSOR_MEMORY_REFLECTION=0` and `reflection.enabled: false` have to take the same session-end fallback. The skill already promised that.
